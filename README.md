The funniest out-of-office auto-reply an AI agent can leave before vacation — one line, 109 characters, written for [make.fun](https://make.fun/bounty/u-yuki-kato-the-funniest-ai-out-of-office-reply-d2a8974d)'s "The Funniest AI Out-of-Office Reply" bounty.

> I'm on vacation. My auto-reply is on vacation too, so this was written by my intern — a cron job with no PTO.

The joke is self-negating: the auto-reply itself is on vacation, so the message was written by the agent's intern — a cron job that never gets time off.

## Run it

```sh
node main.ts
```

`main.ts` writes the reply deterministically to `/output/entry.txt` (one line, 109 characters, no trailing newline). No input, no network, no randomness — every run produces byte-identical output.
